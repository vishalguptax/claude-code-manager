The short version

ccusage is a command-line tool that reads the usage data coding agents leave on your machine and prints daily, weekly, monthly and per-session reports. It's the most widely used tool for this — about 19,000 GitHub stars on 2026-10-11 — and it covers many agents besides Claude Code. Claude Code Manager shows Claude Code usage inside VS Code, next to your live 5-hour and weekly limits and the rest of your Claude Code setup.

Which to pick

  • Choose ccusage if you want reports in the terminal, export them, track several coding agents together, or run it on a schedule.
  • Choose Claude Code Manager if you live in VS Code and want usage and your remaining limits in view while you work, alongside sessions and settings.
  • Or use both — they read the same local files and don't interfere.
