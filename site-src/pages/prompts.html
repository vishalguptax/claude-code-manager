~/.claude/history.jsonl

Your Claude Code prompt history, searchable

Every prompt you send is appended to ~/.claude/history.jsonl, with the project it came from. The arrow-up history in a terminal only goes so far; the Prompts tab searches the whole file.

  • Search across every project at once, full text.
  • Repeated prompts collapse into one row with a count, instead of filling the list.
  • Copy a prompt to reuse it, or open the session it came from.
