Where each editor installs extensions from

Claude Code Manager is the same extension in every editor; what changes is which registry the editor's Extensions view searches. It's published to both.

Can't find it? Download the .vsix from Open VSX and use Extensions: Install from VSIX…, which VS Code, VSCodium, Theia and Gitpod document.

What's the same everywhere

  • It reads the same ~/.claude/ wherever Claude Code runs on your machine, so a session started in one editor's terminal shows up in another's sidebar.
  • Resume returns to the editor you're in. Links into the official Claude Code extension use the running editor's own URL scheme rather than vscode://, so they don't launch a different app.
  • The secondary sidebar option needs VS Code 1.106 or later; editors on an older VS Code base use the primary sidebar.

Anthropic's own docs say the official Claude Code extension also installs in VS Code forks such as Devin Desktop and Kiro, from Open VSX, and suggest running the CLI in the editor's terminal where it can't. Claude Code Manager works with either.
