SKILL.md

Where Claude Code skills come from

  1. ~/.claude/skills/PersonalYour own skills, available in every project.
  2. .claude/skills/ProjectSkills committed with a repository, shared with everyone who works on it.
  3. pluginsPluginSkills that come with an installed plugin.
  4. skills/synced/Synced from claude.aiSkills synced from your claude.ai account.

What you can do from the Skills tab

  • See each skill's scope at a glance, with a badge on every row.
  • Read it — the detail view shows the description; open SKILL.md in the editor in one click.
  • Launch Claude with it, in a terminal or in the official extension's chat.
  • Delete one you no longer want, after a confirmation.

Skills and custom slash commands now work the same way in Claude Code: a .claude/commands/deploy.md file and a .claude/skills/deploy/SKILL.md folder both give you /deploy. See slash commands.
