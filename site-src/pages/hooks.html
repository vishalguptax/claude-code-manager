What the Hooks tab does

  1. full commandRead every hookGrouped by event, with its matcher, scope and the exact command it runs.
  2. _disabled_hooksTurn one off, keep itA disabled hook is moved aside in the same file, so turning it back on restores it exactly.
  3. scope → event → matcher → commandAdd one with a guided formPick where it goes, which event, which tools it matches, and the command — no JSON.
