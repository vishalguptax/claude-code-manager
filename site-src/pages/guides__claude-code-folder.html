Two places: a folder and a file

Claude Code keeps your user-level data in ~/.claude/ and its app state in a single file next to it, ~/.claude.json. Each project can also have its own .claude/ folder and a .mcp.json. Set CLAUDE_CONFIG_DIR and Claude Code uses that folder instead of ~/.claude/. Anthropic's .claude directory reference documents each file in depth; this page is the map.

What's in ~/.claude.json

App state rather than settings: your signed-in account, UI toggles, MCP servers you added at user or local scope, and per-project state such as which MCP servers you've switched off. Claude Code rewrites it often, so close Claude Code before editing it by hand.

Which settings file wins

From highest to lowest: managed settings set by your organisation, command-line --settings, .claude/settings.local.json, .claude/settings.json, then ~/.claude/settings.json. A value set higher up overrides the same key lower down. (Anthropic: settings)

Back it up or move it

Copying ~/.claude/ and ~/.claude.json moves your whole setup, transcripts included — but not a macOS Keychain login. Claude Code Manager's Export Brain packs the parts you write yourself (CLAUDE.md, settings, skills, commands, agents, memory, user-level MCP servers) into one zip, and Import Brain shows conflicts before writing.
