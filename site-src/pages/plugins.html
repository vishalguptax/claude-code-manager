Installed is not the same as enabled

Claude Code keeps what's installed in ~/.claude/plugins/ and what's switched on in enabledPlugins in your settings files — per scope. The Plugins tab puts both side by side.

  1. per scopeOn or off, whereSee whether each plugin is enabled at user, project or local scope, and change it.
  2. mismatchPlugins that don't add upA plugin enabled from a marketplace your policy doesn't allow, or a settings entry with nothing installed behind it, is flagged.
  3. marketplacesBrowse and installBrowse the marketplaces you've added and install with Claude Code's own claude plugin install, run in a terminal.
  4. openLook insideOpen a plugin's folder or the settings file that enables it, or copy its ID.
