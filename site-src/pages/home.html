Local-first

It reads your machine. It tells no one.

No telemetry, no network client

No analytics and no background traffic. The extension reads and writes files under ~/.claude/. When you ask it to log in or install a plugin, it starts Claude Code's own CLI in a terminal.

Limits without your token

The Quota card reads the 5-hour and weekly figures Claude Code already hands its statusline, cached to a local file. It never calls Anthropic.

Honest about logins

Account profiles keep a local copy of each saved login's tokens in ~/.claude/manager-accounts/, in the same plaintext format Claude Code uses on Linux and Windows. You're told before the first one is saved.
