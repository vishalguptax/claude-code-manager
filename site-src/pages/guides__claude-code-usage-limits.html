The two limits

Anthropic's help center says: "Both Pro and Max plans have a five-hour session limit and a weekly limit." Max plans also have a separate weekly limit for one model family. The limits are shared between Claude (the apps) and Claude Code, so time on claude.ai counts too. (Anthropic: using Claude Code with Pro or Max)

  • The five-hour limit caps how much you can use within a five-hour session window.
  • The weekly limit caps total use across the week and resets once a week.

Anthropic doesn't publish fixed token numbers for these windows, and it has changed the limits several times — so treat any number you read on a forum as dated. Check your plan's page in your claude.ai settings for what applies to you.

When you hit a limit

  • Wait for the reset. /usage and the statusline data both give the reset time.
  • Use less per turn. Long sessions carry a lot of context; starting a fresh session or compacting keeps each request smaller. Switch off MCP servers you aren't using — see disabling MCP servers.
  • Choose a lighter model for routine work with /model.
  • Pay as you go. Anthropic's help center describes an option to continue with API credits once you hit a limit, and how to opt out of it.

Where Claude Code Manager fits

It doesn't change your limits. It shows them without a network call, next to your token usage by model, project and tool, so you can see what used them up. See the usage tracker.
