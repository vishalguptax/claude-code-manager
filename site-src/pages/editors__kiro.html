Install it in Kiro

  1. Kiro's Extensions view searches open-vsx.org by default. Search Claude Code Manager and install.
  2. Open the sidebar with Ctrl/Cmd+Alt+C.
  3. Install Claude Code if you haven't: Anthropic's docs name Kiro as an editor the official Claude Code extension installs in, from Open VSX.

If your organisation points Kiro at a private registry (Kiro supports this through OS policies), ask for the extension to be added, or install the .vsix by hand.

Kiro and Claude Code side by side

Kiro has its own agent and spec workflow; Claude Code Manager only manages Claude Code's files. If you run Claude Code in Kiro's terminal or through the official extension, its sessions, skills, MCP servers and limits all show up in the sidebar like anywhere else.
