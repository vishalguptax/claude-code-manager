What kind of GUI do you want?

Some tools replace the terminal with a full app you chat in. Others add a web interface you can reach from your phone. Others live inside your editor. Claude Code Manager is the last kind, and it doesn't replace the chat — it manages what Claude Code keeps on disk. Here's the field, from each project's own description.

Choosing

  • Want to chat in a window that isn't a terminal? Use the official extension, or a desktop app like opcode or Nimbalyst.
  • Want Claude Code on your phone or another machine? A web UI such as CloudCLI.
  • Want to dig into what a session did, call by call? claude-devtools.
  • Already in VS Code, and want to find, sort and fix everything Claude Code leaves behind? Claude Code Manager — alongside any of the above.
