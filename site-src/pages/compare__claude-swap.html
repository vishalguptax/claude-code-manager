The short version

claude-swap (cswap) is a command-line account switcher for Claude Code, installed with uv or pipx. Its README describes switching without logging out, switching for you before you hit a rate limit, a dashboard of each account's 5-hour and 7-day usage, and running accounts in parallel; it works with the CLI and the VS Code extension. Claude Code Manager switches saved accounts from VS Code's sidebar or command palette, next to your usage and the rest of your setup.

Which to pick

  • Choose claude-swap for automatic rotation when an account nears its limit, parallel accounts, or a terminal-only workflow.
  • Choose Claude Code Manager to switch from your editor without leaving it, with sessions, usage and settings in the same place.

Both keep copies of your logins on your machine; read each project's notes on where.
