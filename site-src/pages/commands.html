Make your own slash command

  1. Create .claude/commands/ in a project (or ~/.claude/commands/ for every project).
  2. Add a Markdown file. Its name is the command: review.md becomes /review. The file's text is the prompt Claude receives.
  3. Run it by typing /review in Claude Code — or find it in the Commands tab and launch it from there.

Anthropic's docs now describe custom commands as skills: .claude/skills/review/SKILL.md gives you the same /review, with room for extra files. Existing command files keep working.
