Install it in VSCodium

  1. VSCodium's Extensions view uses Open VSX by default. Search Claude Code Manager and install.
  2. Or download the .vsix from Open VSX and run Extensions: Install from VSIX….
  3. Run Claude Code in VSCodium's terminal. Open the sidebar with Ctrl/Cmd+Alt+C.

A good fit for a telemetry-free editor

People choose VSCodium to keep telemetry out of their editor. Claude Code Manager matches that: it has no network client and no analytics. It reads and writes files under ~/.claude/, and only runs Claude Code's own CLI in a terminal when you ask it to (to log in, or install a plugin). The source is on GitHub under Apache-2.0.
