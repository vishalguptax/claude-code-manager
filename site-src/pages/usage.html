Account tab → Usage

See where your Claude Code tokens go

Claude Code records token counts for every message in its session files. The Usage view adds them up for the last 7 days, 30 days or all time, and splits them four ways, so a busy week has an explanation.

  • By model — how much went to each Claude model, with cache-hit rates.
  • By project — which repositories used the most.
  • By tool and MCP server — which tools Claude reached for, and how often.
  • Activity heatmap — when you used Claude Code, day by day.

A cost figure shows what those tokens would cost at public API rates, from a price table in the extension. It's a yardstick, not a bill: Pro and Max plans are a flat price.

Your 5-hour and weekly limits, in the status bar

Claude Code already knows how much of your plan's limits you've used: it hands that to its statusline command as rate_limits. Switch on the Quota card and a small tap saves that data to a local file; the extension reads the file. You get both windows as bars, reset times, your weekly pace, and a status bar item that turns amber from 75% and red from 90%.

Nothing is fetched. The numbers are as fresh as Claude Code's last statusline update, and the card shows when that was. Claude Code includes limit data for Pro and Max subscribers after the first reply in a session — see how the limits work.

Turn on the Quota card

  1. Open the Account tab and choose to enable the Quota card (the extension also offers this once on its own).
  2. It adds one statusLine.command entry to ~/.claude/settings.json. If you already had a statusline, it keeps running — the tap passes the data on to it.
  3. Send one message in Claude Code. The card and the status bar fill in.

Turn it off and the entry is removed.
