Windsurf is now Devin Desktop

Cognition renamed the Windsurf desktop app to Devin Desktop. Its docs say extensions now live in ~/.devin/extensions/ instead of ~/.windsurf/extensions/, and that by default it "downloads extensions from an Open VSX mirror". (Devin Desktop FAQ)

Install it

  1. Open the Extensions view and search for Claude Code Manager (publisher vishalguptax).
  2. Install it, then open the sidebar with Ctrl/Cmd+Alt+C.
  3. Make sure Claude Code is installed. Anthropic's docs list Devin Desktop among the VS Code forks the official Claude Code extension installs in; the CLI works in any terminal.

What to expect

  • Same data, same tabs. The extension reads ~/.claude/, so sessions, usage and MCP servers match what you see in any other editor.
  • Resume stays in the app. Deep links into the official extension use the running editor's own URL scheme.
