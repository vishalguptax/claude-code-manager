The short version

Anthropic's Claude Code extension is Claude Code inside VS Code: you chat, review diffs, approve plans and run sessions there. Claude Code Manager doesn't talk to Claude at all. It's a sidebar for the files Claude Code leaves on your machine — every session, prompt, file backup, setting, skill and login — across the CLI and the extension. Install the official one to use Claude Code; add this one to manage what accumulates.

How they work together

  • Resume into the chat. With sessions.resumeIn on auto, a session started in the official extension reopens there; one from the CLI reopens in a terminal.
  • Launch a skill or command into the chat from the Skills and Commands tabs.
  • Sit side by side. On VS Code 1.106 or later, you can move Claude Code Manager to the secondary sidebar, next to the Claude Code panel.
