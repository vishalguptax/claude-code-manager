Restore a file Claude Code changed

  1. Open the Checkpoints tab and pick the session. You'll see each file Claude edited and the versions it saved.
  2. Diff a version against the file as it is now, in VS Code's diff view.
  3. Restore it after a confirmation. A closed file is written back byte for byte; an open one goes through your editor, so you can undo.

What checkpoints cover

Claude Code saves a copy of a file before it edits it, for its own /rewind feature (Esc twice). Those copies are what this tab reads. According to Anthropic's docs, checkpoints don't include files changed by shell commands that Claude ran, or edits made outside Claude Code — for those, use git.
