MEMORY.md

Claude Code's auto memory, out in the open

With auto memory on, Claude Code saves notes about a project to ~/.claude/projects/<project>/memory/, listed in a MEMORY.md index it loads at the start of each session. It's separate from the CLAUDE.md files you write yourself. Notes can go stale, and a wrong note is loaded every time.

  • Browse and search each project's memory files.
  • Find broken links — index entries that point at files that no longer exist.
  • Find orphans — memory files the index doesn't mention.
  • Open, reveal or delete a file you don't want Claude to keep reading.
