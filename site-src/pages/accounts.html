Claude Code Manager: Switch Account

Switch Claude Code accounts in two clicks

  1. Save the account you're signed in to. In the Account tab, save the current login as a profile and give it a name, like Work.
  2. Sign in to the next one. Choose Log in as a new account: the extension starts claude and sends /login. Save that one too.
  3. Switch whenever you like from the Account tab, or with Claude Code Manager: Switch Account in the command palette.

What a switch changes, and what it doesn't

  1. ~/.claude.json → oauthAccountThe account identityOnly the login identity is swapped. Projects, MCP servers, history and the rest of the file stay as they are.
  2. Keychain · .credentials.jsonThe Claude credentialOn macOS the Keychain entry; on Linux and Windows ~/.claude/.credentials.json. Other credentials beside it are left alone.
  3. .oauth_refresh.lockSafely, while Claude runsThe switch takes the same lock Claude Code uses when it refreshes a token, and keeps a crash journal so an interrupted switch can be recovered.
  4. profilesEach account's last quotaThe switcher shows the weekly usage each account had when you last used it, so you can pick the one with room left.

Where your tokens are kept

A profile is a folder in ~/.claude/manager-accounts/ holding that login's identity and a copy of its tokens, in plaintext — the same way Claude Code itself stores its login in .credentials.json on Linux and Windows. It never leaves your machine, and the extension tells you this before you save the first profile. Delete a profile and its copy goes with it.

If you'd rather keep accounts fully separate — their own settings and history too — Anthropic documents running each with its own CLAUDE_CONFIG_DIR; the extension reads that variable as well.
