Create and edit subagents without hunting for files

  • See each agent's model as a badge, and its description in the list, so you know what you're reaching for.
  • Create a new agent, edit one, duplicate one as a starting point, or delete it.

A subagent is a Markdown file with frontmatter. The model field takes an alias such as sonnet, opus or haiku, a full model ID, or inherit to use the main conversation's model.
