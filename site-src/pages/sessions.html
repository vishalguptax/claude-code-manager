~/.claude/projects/<project>/<session-id>.jsonl

Your sessions are already files. This makes them findable.

Claude Code saves every conversation as a JSONL file under ~/.claude/projects/, one folder per working directory. The built-in picker (claude --resume or /resume) lists them for the current folder. The Sessions tab reads every folder at once and adds the things a long list needs: search, filters and actions.

Find an old Claude Code session

  1. Widen the date filter. The list opens on recent sessions; choose Week, Month or All.
  2. Pick the project and branch, or choose All projects. The current workspace and branch are marked in the filters.
  3. Search what was said. The search reads the transcripts themselves, so a function name, an error message or a file you discussed is enough.
  4. Resume. Running sessions sit at the top with a live status dot; View jumps to the terminal that's running one.

Resume Claude Code sessions where they belong

  1. sessions.resumeInIn a terminal or in the chatResume opens a session where it started (auto), always in a terminal, always in the official extension's chat, or asks each time.
  2. git checkoutOn the right branchIf the session ran on another branch, you're warned first and offered a checkout, the worktree that already has that branch, or Resume Anyway.
  3. --fork-sessionFork instead of continuingStart a new session from an old one and leave the original untouched.
  4. RestoreReopen a whole workdayRestore your most recent sessions at once, each in its own terminal (4 by default, up to 12).
  5. git worktree addMissing worktree? Recreate itIf a session ran in a worktree that's gone, the extension can recreate the worktree and resume there.

Organise, export and move sessions

  1. pin · archive · renameKeep the list tidyPin the ones you return to, archive the rest, rename any. These live in the extension's own state; Claude Code's files aren't rewritten.
  2. .jsonl · .zip · MarkdownExport and importExport one session as .jsonl, several as a .zip, or copy one as Markdown. Import puts a session in the right project folder on another machine.
  3. temporaryThrowaway sessionsStart a temporary session for a quick question; its transcript is deleted when the terminal closes.
