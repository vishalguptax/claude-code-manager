Install Claude Code Manager in Cursor

  1. Open the Extensions view (Ctrl+Shift+X, or Cmd+Shift+X on macOS).
  2. Search for Claude Code Manager (publisher vishalguptax) and click Install. Cursor serves third-party extensions from Open VSX, through its own proxy that scans them before offering them.
  3. Open the sidebar with Ctrl+Alt+C (Cmd+Alt+C on macOS), or from the status bar.

You also need Claude Code itself — the CLI in Cursor's terminal, the official Claude Code extension (Anthropic's docs give a Cursor install link), or both.

Using it with Claude Code in Cursor

  • Sessions from Cursor's terminal and from the Claude Code extension appear in one list, next to sessions you ran in other editors.
  • Resume opens in Cursor. Links into the official extension's chat use Cursor's own cursor:// scheme, so they land in the window you're in.
  • WSL: when Cursor and Claude Code run against WSL, the folder name Claude Code uses for a project can differ from the path Cursor reports. Export looks the session up by its ID first, so it still finds the right file.

Cursor's own AI features and Claude Code are separate: this extension manages Claude Code's data only.
