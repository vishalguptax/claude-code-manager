# v2.16.0

_Released 2026-09-30_

Your 5-hour and weekly quota now live in the status bar, the Quota card points you to claude.ai's free limit reset when you're near a cap, and Config and Account open on what matters instead of every section at once.

## ✨ Features

- **account: show live quota in the status bar** ([679a27f](https://github.com/vishalguptax/claude-code-manager/commit/679a27f7d54c2f1f358e3931eed373d4b6a4bc6e))

  The status bar item was a static "Claude Code Manager" label. It now reads `5h 72% · 7d 40%` from the local statusline cache, tinted amber from 75% and red from 90%, with reset times in the tooltip. No network call, no OAuth token.

  A window whose reset time has passed shows "reset" rather than its stale figure, and a capture from before an account switch falls back to the plain label. A one-minute recheck catches both while no session is rendering.

- **account: link to claude.ai's free limit reset near a cap** ([7af58e0](https://github.com/vishalguptax/claude-code-manager/commit/7af58e0331acd2f12ebb8b0b7277a1340f33768b))

  Eligible plans occasionally get a free 5-hour or weekly limit reset, but Anthropic offers it only in claude.ai and Claude Desktop, with no API. Triggering it from here would mean replaying claude.ai's private endpoint with your OAuth token, which the Consumer Terms and Claude Code's credential policy forbid. So once either window reaches 90%, the Quota card links to claude.ai's usage settings, and you press the button on Anthropic's own page.

- **webview: open Config and Account on what matters, rest folded** ([0cc565a](https://github.com/vishalguptax/claude-code-manager/commit/0cc565a4fbd0ff6133928b2495519384e12b3359))

  Config used to open with every section expanded: settings, permissions, tab layout, settings history and brain backup in one narrow column. It now opens on Settings alone, with the rest a click away. Usage's breakdown blocks (models, projects, tools, MCP) fold too, and their heading counts still say what's inside.

- **site: add the one-minute launch video tour** ([3565e87](https://github.com/vishalguptax/claude-code-manager/commit/3565e87847bd4686c12ee2ccb67a7145b08b2d3f))

  [claudecodemanager.vishalg.in](https://claudecodemanager.vishalg.in/#tour) has a one-minute tour of the sidebar. It's self-hosted rather than a YouTube embed, so the page that promises zero telemetry sets no tracking cookies. The video is website-only and does not ship in the extension.

## 🐛 Bug Fixes

- **sessions: stop showing other projects' sessions in a folderless window** ([ad6f9fe](https://github.com/vishalguptax/claude-code-manager/commit/ad6f9fe809e251e0aafa7408f8a1fda1f07300ff))

  With no folder open, "This Project" couldn't tell "workspace not reported yet" from "no folder", so it fell back to every project, and Restore and Resume treated other projects' sessions as this one's. Now This Project matches nothing, Restore has nothing to reopen, every session offers "Open project", and resume opens the session's own project instead of resuming in the empty window.

- **mcp: re-enabling a disabled project server takes effect** ([734507b](https://github.com/vishalguptax/claude-code-manager/commit/734507b216fe2e643b761f83ff28565a76ec98d5))

  A project server disabled once could never be shown as enabled again: the disabled state was stamped onto objects shared with the `.mcp.json` cache, and the toggle rewrites a different file, so the stale stamp stuck.

- **sessions: detect worktrees created since the last refresh** ([9931cf5](https://github.com/vishalguptax/claude-code-manager/commit/9931cf5f28621951851d39fda5ad19c6adaae5a4))

  The git worktree list was cached until a reload, so sessions in a worktree Claude created afterwards fell through to the main worktree, and a branch switch kept reporting the old branch.

- **mcp: keep the re-auth banner inside the panel** ([82f656c](https://github.com/vishalguptax/claude-code-manager/commit/82f656cd650f6a6b7d1454f3db2a73a99d1c172f))

  The banner ran 28px past the panel edge, which clipped its "Open /mcp" link.
