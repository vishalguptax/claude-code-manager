# v2.15.1

_Released 2026-09-20_

The sidebar's colours now hold up on every theme — row icons, chevrons and meta text were washed out on Dracula, Solarized Light and others, and the status chips were tuned for dark backgrounds only.

## 🐛 Bug Fixes

- **styles: make the colour layer readable on every theme** ([631cced](https://github.com/vishalguptax/claude-code-manager/commit/631ccedbf63082075a6f681776d9364b5925ede6))

  Row action glyphs, collapse chevrons, palette icons and meta text were barely visible on a number of themes. One token was responsible: it resolved to VS Code's `disabledForeground` — the lowest-contrast colour a theme ships — while eighty call sites used it for UI that is not disabled at all. Those call sites are quiet text and now use the colour VS Code provides for quiet text.

  Two more colours were borrowed from the wrong context. The tab strip took the *panel's* title colour, which themes tune against a different background: Dracula puts `#6272A4` there, 3.36:1 on its sidebar, and the strip's icons came out barely-there purple. As sidebar chrome it now takes the sidebar's own text colour — 5.56:1 on the same theme. Three greens borrowed the Test Explorer's pass glyph behind three different hardcoded fallbacks.

  Separately, the status hues were a dark-theme palette applied unchanged on white, where blue measured 2.53:1, amber 2.10:1 and orange 2.03:1. Light themes now get a light-surface palette, and every hue clears 4.5:1 against its own background. Also fixed: a warning-banner orange hardcoded six times across two files, five fallbacks that rendered white-on-white on a light theme, and rules that dimmed an already-quiet colour a second time.

  Theme colours are used exactly as shipped — no contrast adjustment of a value the theme author chose — so the panel agrees with the editor around it.

- **terminal: drop the custom tab icon** ([e5db0d7](https://github.com/vishalguptax/claude-code-manager/commit/e5db0d716585c116c2cdcec2823f9ea4e612624e))

- **sessions: persist collapsed sections for Active, Today and Yesterday** ([95d87eb](https://github.com/vishalguptax/claude-code-manager/commit/95d87ebe2b393c3f1334691ffd3938a5022c3d9e))

  Collapse state was already persisted, but the relative labels were filtered out of it on both the read and write paths. Those three sections hold most of the list, so collapsing anything that mattered never survived a reload. Collapsing a section is a statement about the section, not about the sessions sitting in it right now.
