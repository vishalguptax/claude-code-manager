# v2.11.0

_Released 2026-09-16_

Four new tabs — Checkpoints, Prompts, Memory and Plugins — surfacing data Claude Code already keeps on disk but nothing could read, plus unread marks and an archive for sessions, and a panel that now opens from either side bar.

## ✨ Features

- **checkpoints: browse and restore the versions Claude Code keeps** ([25bc2f4](https://github.com/vishalguptax/claude-code-manager/commit/25bc2f4)) — Claude Code silently versions every file it edits under `~/.claude/file-history/`. Nothing surfaced it. The tab lists what each session touched, diffs any version, and restores one. An open file is restored through a `WorkspaceEdit` so <kbd>Ctrl</kbd>+<kbd>Z</kbd> reverses it; a closed one byte-exact, preserving CRLF and the trailing newline.
- **prompts: search everything you have ever asked Claude** ([9cbd951](https://github.com/vishalguptax/claude-code-manager/commit/9cbd951)) — every prompt across every project, streamed and cached by mtime so typing filters in memory. Consecutive retries collapse into one row with a count.
- **memory: browse, search and prune Claude's auto-memory** ([1266856](https://github.com/vishalguptax/claude-code-manager/commit/1266856)) — with broken-link and orphan detection, which is the part you cannot get by listing the directory.
- **plugins: show what is installed, what is enabled, and what disagrees** ([711400c](https://github.com/vishalguptax/claude-code-manager/commit/711400c)) — surfaces the three states nothing else reports: installed but not enabled, enabled from a marketplace the policy does not allow, and enabled with nothing installed behind it.
- **sessions: unread marks and an archive** ([18af2c5](https://github.com/vishalguptax/claude-code-manager/commit/18af2c5)) — archiving hides a session without deleting it, and unread tracks activity since you last opened one.
- **extension: open the panel from either side, and from both at once** ([29a74ba](https://github.com/vishalguptax/claude-code-manager/commit/29a74ba)) — the container is contributed to both the activity bar and the secondary side bar. Host state stays single; only the webviews are per-panel, so two panels keep independent tabs and filters.
- **account: read the pr, worktree and repo blocks Claude Code already sends** ([8964893](https://github.com/vishalguptax/claude-code-manager/commit/8964893)) — PR/MR number with review state, worktree name and branch, and `owner/name`, all from status-line fields that were being discarded.
- **webview: turn on the prompts, memory and plugins tabs** ([8557b07](https://github.com/vishalguptax/claude-code-manager/commit/8557b07))
- **extension: offer the panel in the secondary sidebar** ([f3eb8ac](https://github.com/vishalguptax/claude-code-manager/commit/f3eb8ac))

## 🐛 Bug Fixes

- **sessions: match Claude Code's project-slug rule exactly** ([392d505](https://github.com/vishalguptax/claude-code-manager/commit/392d505)) — the slug replaces every non-alphanumeric character, not just separators, and truncates past 200 chars with a hash. A project path containing a dot, space or underscore produced a directory Claude Code never reads, which broke ephemeral-session cleanup and pointed export/import somewhere `--resume` does not look.
- **sessions: stop corrupting text that straddles a 64 KB read boundary** ([438cffc](https://github.com/vishalguptax/claude-code-manager/commit/438cffc)) — every streaming reader decoded each chunk independently, so a multi-byte character spanning the boundary became three replacement characters. Any transcript with emoji or non-Latin text was affected, roughly once per 64 KB.
- **sessions: refuse to follow symlinks out of the transcript tree** ([ada356e](https://github.com/vishalguptax/claude-code-manager/commit/ada356e)) — six reads under `~/.claude/projects` followed symlinks; now `O_NOFOLLOW`, with an `lstat` pre-check on Windows.
- **sessions: stop marking every session unread, and deliver the fields that say so** ([babc10f](https://github.com/vishalguptax/claude-code-manager/commit/babc10f)) — unread now starts from a baseline, so enabling it no longer lights up your whole history. `archived` and `readAt` were also missing from the message schema and silently stripped in transit, which meant archiving a session did not hide it.
- **protocol: register the host replies the new tabs wait on** ([ba60286](https://github.com/vishalguptax/claude-code-manager/commit/ba60286)) — three replies were declared in types but had no schema, so the message bus discarded them and those tabs never loaded.
- **account: read the prompt-cache miss diagnosis as the object it is** ([aa331a9](https://github.com/vishalguptax/claude-code-manager/commit/aa331a9)) — it was coerced to a string, so the "Last miss" line had never once rendered. Also picks up the spend-limit window, real context token counts and the session's `/rename` title.
- **webview: put the new tabs back on the shared UI contract** ([1ac6957](https://github.com/vishalguptax/claude-code-manager/commit/1ac6957)) — Checkpoints could not scroll, search bars sat at the wrong inset and row spacing disagreed between tabs. Around 300 lines of duplicated stylesheet deleted.
- **webview: rebuild the plugins tab on the contract, and reveal row actions generally** ([21ad4c9](https://github.com/vishalguptax/claude-code-manager/commit/21ad4c9)) — row action buttons were revealed by an explicit list of row classes that never named the plugins row, so its copy button was invisible from the day it shipped.
- **webview: give the virtualized lists real list semantics** ([1e01d99](https://github.com/vishalguptax/claude-code-manager/commit/1e01d99)) — windowed lists reported their visible slice rather than the real total, so a screen reader announced "1 of 6" for a list of six hundred.
- **webview: draw the outline icon button in its labelled twin's colour** ([844581f](https://github.com/vishalguptax/claude-code-manager/commit/844581f)) — the collapse-all chevrons sat at a different shade from the "Select" button beside them.
- **extension: make panel placement a setting, not a version swap** ([cf00130](https://github.com/vishalguptax/claude-code-manager/commit/cf00130))
