# v2.12.0

_Released 2026-09-16_

Choose which sidebar tabs show and in what order, right from the Config tab — plus a fix that gets terminal tab animations working the way they do when you type `claude` yourself.

## ✨ Features

- **config: manage sidebar tabs from inside the panel, not just settings.json** ([472f3c5](https://github.com/vishalguptax/claude-code-manager/commit/472f3c581f3931b0a0c88c2299ea5739682602fd)) — a "Sidebar tabs" section in Config: a checkbox per tab to show or hide it, a drag handle plus up/down buttons to reorder it. Every row stays in the list even when hidden, so there's always a way back.
- **webview: let the user choose which tabs show, and in what order** ([e093e35](https://github.com/vishalguptax/claude-code-manager/commit/e093e3574272c5b3e1f4c99eddb53ee6096d4f0a)) — two new settings underneath, `claudeManager.hiddenTabs` and `claudeManager.tabOrder`, editable from VS Code's own Settings UI too. A hidden-tabs list that would hide every tab is refused rather than honoured, so a stray edit can never blank the whole panel.

## 🐛 Bug Fixes

- **extension: wait for shell integration before the first command, so the terminal tab actually animates** ([a883360](https://github.com/vishalguptax/claude-code-manager/commit/a8833604eec4e9afef1bd5031993a307dc44ebf2)) — terminals this extension opened never showed VS Code's native busy spinner or Claude Code's own progress ring, because the very first command was sent before the shell finished activating integration. Now waits for it (bounded, so a shell without integration support still gets its command).
- **webview: put Config back up front, and fix the intro's blank descriptions** ([6ada731](https://github.com/vishalguptax/claude-code-manager/commit/6ada73197949285d4f86dd55dd6b0d043f372963)) — Config moves to third by default, alongside Sessions and Account. Separately, the first-run intro had no description text for four tabs added in the previous release; fixed, with a test that catches it if it happens again.
