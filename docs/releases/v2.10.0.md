# v2.10.0

_Released 2026-09-13_

A ground-up pass over the sidebar. Every tab now renders from one shared component layer instead of seven private copies, with a cross-tab search on Cmd/Ctrl+K, collapsible sections on Account and Config, per-row switches for MCP servers, and tooltips that appear only where they say something.
